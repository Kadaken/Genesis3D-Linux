# Security policy

## Reporting a vulnerability

Please do not publish a working exploit or malicious asset in a public issue.
Report security-sensitive parser, memory-safety, path-handling, or dependency
problems privately through GitHub's security-advisory interface for this
repository. If that interface is unavailable, contact `support@kadaken.com`
with the subject `Genesis3D security report`.

Include the affected commit, platform, reproduction steps, and sanitizer output
when safe to do so. Do not attach copyrighted game assets; provide an original
minimal fixture or instructions for creating one.

## Supported branch

Security fixes target the current `main` branch. Historical Windows project
files and excluded driver backends are retained only for reference and are not
represented as supported or security-maintained.
